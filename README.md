# 📝 React ToDo App using Redux Toolkit & Tailwind CSS

A simple and modern **ToDo List application** built using **React**, **Redux Toolkit**, and **Tailwind CSS**.

---

## 🚀 Features

- 🆕 Add new todos
- ✏️ Edit todos
- ❌ Delete todos
- ✅ Mark todos as completed
- 🔄 Global state management using Redux Toolkit
- 💅 Responsive design with Tailwind CSS
